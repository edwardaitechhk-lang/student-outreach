💛 WhatsApp 客戶保暖工具

由 Notion CRM 自動拉客戶，用你嘅 WhatsApp 逐個發送個人化關心訊息。

⚙️ 首次設定 — 連接你嘅 Notion CRM

係你嘅 Notion CRM 必須包含 姓名、WhatsApp 兩個 property（其他 optional）。
Step 1：喺 Notion 整一個 Integration
去 notion.so/my-integrations → + New integration → Name 填「WhatsApp Warmup」→ Submit → copy Internal Integration Secret（ntn_...）
Step 2：分享 CRM 畀 Integration
開你個 Notion CRM database page → 右上 ⋯ → Connections → 揀啱頭先個 integration → 之後 copy 個 URL paste 落面（或者直接 paste database ID）
Step 3：Product Filter（可選）
如果你只想 send 俾某個「產品」標籤嘅人（例如「12 Agent 課程」），填入；想 send 俾全部 CRM 就留空。
